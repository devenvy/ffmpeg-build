Third-Party Modified Version of the Fraunhofer FDK MPEG-H Software

Build modification, 2026-10-21: on 32-bit ARM Linux, the compiler renames schur_div to
_mpeghdec_schur_div. Upstream's symbol prefix header omits this architecture-specific
C++ symbol, which otherwise collides when statically linking fdk-aac and mpeghdec
into the same FFmpeg library. No algorithm or public API is changed.

Build modification, 2026-10-22: opt-in Linux x64 shared builds add an engine-defined
full-version SONAME, because upstream supplies no SONAME, and restrict dynamic
exports to the complete mpeghdecoder_* and mpegh_UI_* public namespaces. Static
builds retain their existing library naming and symbol prefixing. The shared
build embeds its private C++ runtime and uses the common system unwinder. No
codec algorithm or public function signature is changed.
