devenvy/ffmpeg-build uses PyTorch 2.7.1's native CMake CPU build and complete
recursive source checkout. This release supports the C++17 configure probes in
stock FFmpeg 8 and 9. Python is a build tool only; its pinned generator sources
are retained. No Python runtime, GPU runtime or pretrained model is shipped.

Distributed inference, external BLAS, OpenMP, oneDNN, XNNPACK and profiling
integrations are disabled through native CMake options. Desktop BLAS=Eigen
selects upstream's scalar fallback with external BLAS discovery disabled; this
does not claim to enable the mobile-only EigenBLAS implementation.

The complete headers and CMake SDK are preserved from the native shared build.
No symbols, source files or native export policies are rewritten.

This engine offers the native shared Torch, Torch-CPU, c10 and global-dependencies owners.
The native CAFFE2_LINK_LOCAL_PROTOBUF option controls bundled Protobuf linkage.
Shared mode uses the system C++ runtime and unwinder. Recipients need compatible
system libraries. Static FFmpeg integration is not offered: its native registration
closure cannot be scoped to one owner through stock FFmpeg's transitive link flags.

FFmpeg's stock Torch wrapper requires a model parameter to discover its device.
Use a compatible TorchScript model with at least one parameter and nireq=1.
Both async modes are checked through natural EOF, early cutoff, empty input and
invalid-model cleanup. Combined backends must preserve their native dependency owners.
